Lumen Drift is a 2D canvas arena survival game: fly the lantern-ship through the Hollow, a dark place lit only by your own light. Survive 10 waves of wisps, spinners, splitters, hulks and the Gloom Titan, collect light shards, grab power-ups (tri-shot, rapid fire, aegis shield, magnet, repair), chain kills into combos and dash through danger. Keyboard and mouse, synthesized WebAudio sound, title / pause / game-over / victory screens, best score saved locally. Screenshots are real renders of the game in a browser.

## Run it

```sh
cd game
python3 -m http.server 8000
```

Then open http://localhost:8000/ in a browser.
